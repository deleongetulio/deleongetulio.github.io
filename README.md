# getuliodeleon.com

Source for my personal site, served via GitHub Pages. Plain static HTML/CSS,
no build step - the site is a single page of professional identity, not a
blog, so a generator would add maintenance without benefit.

- `index.html` - English (canonical)
- `es/index.html` - Spanish
- `style.css` - shared stylesheet (responsive, dark-mode aware)
- `img/` - profile photo and project screenshots
- `CNAME` - custom domain for GitHub Pages

## Local preview

```
python -m http.server 8033
```
